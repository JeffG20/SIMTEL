SIMTEL - Interfaz web inicial

ESTRUCTURA
- index.html: estructura de la página.
- css/style.css: estilos, colores y diseño adaptable.
- js/app.js: menú, buscador, ventanas modales y acciones de demostración.
- images/obra.jpg: imagen de portada (debes agregar tu propia fotografía).
- images/productos/: carpeta para fotografías de productos.

CÓMO ABRIR
1. Extrae la carpeta SIMTEL.
2. Agrega una imagen llamada obra.jpg dentro de la carpeta images.
3. Abre index.html en Chrome, Edge o Firefox.

IMPORTANTE
Esta es una interfaz de demostración. El inicio de sesión, registro, perfil, carrito,
pedidos y PQRS todavía requieren un backend, base de datos y validaciones de seguridad.
Cambia el correo de contacto en index.html por el correo real de SIMTEL.
